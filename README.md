# Level 2 Adult ESL Curriculum (website)

A free curriculum for Level 2 (high-beginner) adult English classes: a 16-week semester plan, a weekly class routine, and Lessons 1–4 with picture vocabulary, listening audio, grammar boxes, homework, and full teacher plans.

**Live site:** https://sdpursley.github.io/ESL-Curriculum/

## What's here

- Plain HTML and CSS. No build step, no JavaScript, no external CDNs. All links are relative.
- `index.html`: home (course overview, semester plan, class routine)
- `lesson1.html` … `lesson4.html`: Student section and Teacher section for each lesson
- `downloads.html`: the full curriculum (PDF, DOCX) and listening MP3s
- `about.html`: license, credits, and independence notice
- `style.css`, `images/`, `audio/`, `downloads/`
- `.nojekyll`: tells GitHub Pages to serve the files as they are

## Publish on GitHub Pages

Put these files at the root of the repository, then go to **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
