# Level 2 Adult ESL Curriculum — website

Source for the public website of the **Level 2 Adult ESL Curriculum** (13 lessons plus midterm and final exams):
lesson pages for learners, teacher plans, an in-browser slide presenter, listening audio, vocabulary pictures,
and downloadable slides, exams and the full curriculum document.

Live site: https://sdpursley.github.io/ESL-Curriculum/

## Stack

- [Vite](https://vite.dev/) 6 with `base: './'` (relative asset paths, so the site works under `/ESL-Curriculum/`)
- React 18 + TypeScript
- Tailwind CSS 4, configured through the `@tailwindcss/vite` plugin in `vite.config.ts`. There is no
  `tailwind.config.*` or PostCSS config; the CSS entry is `src/index.css` (`@import "tailwindcss";` plus a `@theme` block).
- React Router 6 with `HashRouter` (set up in `src/main.tsx`), so no server-side routing is needed on GitHub Pages
- Radix Tabs, lucide-react icons
- Lexend Deca font for slides/presenter: `src/assets/fonts/LexendDeca-Variable.woff2` (bundled by Vite via `src/presenter/presenter.css`)

## Routes (hash-based)

| Route | Page |
|---|---|
| `#/` | Home |
| `#/lessons` | All lessons |
| `#/lesson/:n` | Lesson *n* (learner view) |
| `#/lesson/:n/teacher` | Lesson *n*, teacher tab (`#/lesson/:n/:tab`) |
| `#/downloads` | Downloads (slides, curriculum document) |
| `#/exams` | Midterm and final exams |
| `#/about` | About, license and credits |
| `#/present/:n` | Full-screen slide presenter for lesson *n* |

Unknown routes redirect to `#/`. Route definitions are in `src/App.tsx`.

## Where things live

- **Home page and page copy**: `src/App.tsx`; site-wide settings and links: `src/config.ts`
- **Lesson data**: `src/content.json` (loaded via `src/content.ts`), generated from `curriculum/Level2_Curriculum_v5_public.md` by `scripts/export_content.py` (`npm run content`)
- **Slide data**: `src/decks/lesson1.json` … `lesson13.json`, generated by `scripts/export_deck.py` from the PowerPoint files in `public/downloads/slides/`; presenter code in `src/presenter/`
- **Image sizes**: `src/sizes.json` (picture dimensions used for layout)
- **Static files** (copied as-is into the build): `public/images/` (vocabulary pictures, `CREDITS.md`),
  `public/audio/` (listening MP3s), `public/downloads/` (slides, exams, curriculum DOCX/PDF), `public/.nojekyll`
- **Curriculum source**: `curriculum/Level2_Curriculum_v5_public.md`, built into PDF/DOCX and exam packets by `curriculum/build.sh`
- **Generation tools**: `tools/audio/` (Chatterbox TTS audio pipeline, voice reference clips, ASR checks) and `tools/images/`
  (vocabulary picture generators). They are not part of the site build; see MAINTAINING.md.
- `EXAMS_PAGE_PLAN.md`: design notes for the exams page

## Maintaining everything else

**See [MAINTAINING.md](MAINTAINING.md)** for step-by-step instructions on editing lessons and rebuilding the curriculum
PDF/DOCX and exams (`curriculum/`), updating the slide decks, vocabulary pictures (`tools/images/`), and listening audio
(`tools/audio/`, Chatterbox TTS). Python requirements: `tools/requirements-docs.txt`, `tools/images/requirements.txt`,
`tools/audio/requirements.txt`. System programs: LibreOffice (PDFs), ffmpeg (audio), Cairo and DejaVu fonts (pictures).

## Local development

```bash
npm ci
npm run dev      # start the dev server (Vite)
npm run build    # type-check and build to dist/
npm run preview  # serve dist/ locally
```

## Publishing

Pushing to `main` runs `.github/workflows/pages.yml`, which installs dependencies, builds the site and deploys
`dist/` to GitHub Pages. The repository's Pages source is set to **GitHub Actions**. Build output (`dist/`) is
not committed.
