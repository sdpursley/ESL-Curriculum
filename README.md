# Adult ESL Curriculum (Level 1 and Level 2) — website

Source for the public website of the free **Adult ESL Curriculum**. The home page lets visitors choose a level:

- **Level 1** (beginner): 13 lessons planned over 16 weeks. **Lesson 1 is published**; Lessons 2–13 are listed as "coming soon".
- **Level 2** (high beginner): 13 lessons plus midterm and final exams.

Each lesson has pages for learners, a teacher plan, an in-browser slide presenter, listening audio, vocabulary pictures,
and downloadable slides and documents.

Live site: https://sdpursley.github.io/ESL-Curriculum/

## Stack

- [Vite](https://vite.dev/) 6 with `base: './'` (relative asset paths, so the site works under `/ESL-Curriculum/`)
- React 18 + TypeScript
- Tailwind CSS 4, configured through the `@tailwindcss/vite` plugin in `vite.config.ts`. There is no
  `tailwind.config.*` or PostCSS config; the CSS entry is `src/index.css` (`@import "tailwindcss";` plus a `@theme` block).
- React Router 6 with `HashRouter` (set up in `src/main.tsx`), so no server-side routing is needed on GitHub Pages
- Radix Tabs, lucide-react icons
- Lexend Deca font for slides/presenter: `src/assets/fonts/LexendDeca-Variable.woff2` (bundled by Vite via `src/presenter/presenter.css`)

## Routes (hash-based)

| Route | Page |
|---|---|
| `#/` | Home: choose Level 1 or Level 2 |
| `#/about` | About, license and credits (both levels) |
| **Level 1** | |
| `#/level1` | Level 1 overview (lesson list with "coming soon" lessons, semester plan, class routine) |
| `#/level1/lessons` | Level 1 lesson list |
| `#/level1/lesson/:n` | Level 1 lesson *n* (`#/level1/lesson/:n/:tab`, tab = `student`, `teacher` or `downloads`) |
| `#/level1/downloads` | Level 1 downloads |
| `#/level1/present/:n` | Full-screen slide presenter for Level 1 lesson *n* |
| **Level 2** (original URLs, unchanged) | |
| `#/level2` | Level 2 overview (the former home page) |
| `#/lessons` | All Level 2 lessons |
| `#/lesson/:n` | Lesson *n* (learner view); `#/lesson/:n/teacher` = teacher tab (`#/lesson/:n/:tab`) |
| `#/downloads` | Downloads (slides, curriculum document) |
| `#/exams` | Midterm and final exams |
| `#/present/:n` | Full-screen slide presenter for lesson *n* |
| `#/level2/lessons`, `#/level2/lesson/:n(/:tab)`, `#/level2/present/:n`, `#/level2/downloads`, `#/level2/exams` | Aliases that redirect to the Level 2 URLs above |

Unknown routes redirect to `#/` (unknown `#/level1/...` routes to `#/level1`). Route definitions are in `src/App.tsx`.

## Where things live

- **Level picker, Level 2 pages, header/footer, About**: `src/App.tsx`; **Level 1 pages**: `src/level1.tsx`; site-wide settings and links: `src/config.ts`
- **Lesson data**: `src/content.json` (loaded via `src/content.ts`), generated from `curriculum/Level2_Curriculum_v5_public.md` by `scripts/export_content.py` (`npm run content`)
- **Level 1 lesson data**: `src/content_level1.json` (loaded via `src/content_level1.ts`), generated by the same `scripts/export_content.py` from `level1/curriculum/` (lesson list from `Level1_Scope_and_Sequence.md`, lesson pages from `Level1_Lesson<N>.md`)
- **Slide data**: `src/decks/lesson1.json` … `lesson13.json`, generated by `scripts/export_deck.py` from the PowerPoint files in `public/downloads/slides/`;
  Level 1: `src/decks/level1/lesson<N>.json` (`scripts/export_deck.py <pptx> <N> --level 1`, picked up automatically); presenter code in `src/presenter/`
- **Image sizes**: `src/sizes.json` (picture dimensions used for layout)
- **Static files** (copied as-is into the build): `public/images/` (vocabulary pictures, `CREDITS.md`),
  `public/audio/` (listening MP3s), `public/downloads/` (slides, exams, curriculum DOCX/PDF), `public/.nojekyll`
- **Level 1 static files**: `public/level1/` (`images/`, `audio/`, `downloads/` incl. `slides/`), copied from the Level 1 sources in `level1/` by the scripts
- **Curriculum source**: `curriculum/Level2_Curriculum_v5_public.md`, built into PDF/DOCX and exam packets by `curriculum/build.sh`;
  Level 1: `level1/` (`curriculum/` lesson Markdown + scope and sequence + `build.sh`, `images/`, `audio/`, `slides/`)
- **Generation tools**: `tools/audio/` (Chatterbox TTS audio pipeline, voice reference clips, ASR checks) and `tools/images/`
  (vocabulary picture generators). They are not part of the site build; see MAINTAINING.md.
- `EXAMS_PAGE_PLAN.md`: design notes for the exams page

## Maintaining everything else

**See [MAINTAINING.md](MAINTAINING.md)** for step-by-step instructions on editing lessons and rebuilding the curriculum
PDF/DOCX and exams (`curriculum/`), updating the slide decks, vocabulary pictures (`tools/images/`), and listening audio
(`tools/audio/`, Chatterbox TTS). **Level 1** (rebuilding, swapping the audio, adding the next lesson) is section 8 of MAINTAINING.md. Python requirements: `tools/requirements-docs.txt`, `tools/images/requirements.txt`,
`tools/audio/requirements.txt`. System programs: LibreOffice (PDFs), ffmpeg (audio), Cairo and DejaVu fonts (pictures).

## Local development

```bash
npm ci
npm run dev      # start the dev server (Vite)
npm run build    # type-check and build to dist/
npm run preview  # serve dist/ locally
```

## Publishing

Pushing to `main` runs `.github/workflows/pages.yml`, which installs dependencies, builds the site and deploys
`dist/` to GitHub Pages. The repository's Pages source is set to **GitHub Actions**. Build output (`dist/`) is
not committed.
