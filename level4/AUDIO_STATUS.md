# Level 4 listening audio: status

**Some Level 4 listening files are drafted below.** A person still needs to listen to each passing file once. Each lesson has a listening script and a cast file ready for the audio handoff in `level4/audio/tools/` (`scripts/script_L4_LN.py`, `cast/cast_L4_LN.json`). The lesson books say "not recorded yet" and link to no audio file.

When audio is made, it will use synthetic voices made with Chatterbox TTS (Resemble AI, MIT License), cloned from synthetic reference clips made with Kokoro-82M (Apache License 2.0). No real person's voice is used. Female characters get female reference voices.
