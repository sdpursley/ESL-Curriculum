### C. Grammar (20 points)

**Part 1.** Circle the correct words (15 points).

1. Have you ever ______ a horse? ( **rode** / **ridden** )

2. I ______ to Mexico City in 2019. ( **went** / **have gone** )

3. Maria ______ worked here since 2021. ( **have** / **has** )

4. I have lived in this city ______ five years. ( **for** / **since** )

5. We have had this car ______ 2020. ( **for** / **since** )

6. When ______ you move here? In 2018. ( **did** / **have** )

7. Have you finished the inventory ______? ( **already** / **yet** )

8. I've ______ restocked the shelves. They look great. ( **already** / **yet** )

9. You have a fever. ______ you see a doctor? ( **Why don't** / **Why do** )

10. Would you mind ______ the window? ( **to close** / **closing** )

11. If I won a lot of money, I ______ buy a house. ( **will** / **would** )

12. If I ______ you, I'd tell the truth. ( **were** / **am** )

13. I can't buy it. I don't have ______ money. ( **enough** / **too** )

14. There are too ______ people on the bus. ( **much** / **many** )

15. You ______ wear a uniform on Saturday. Casual clothes are fine. ( **mustn't** / **don't have to** )
