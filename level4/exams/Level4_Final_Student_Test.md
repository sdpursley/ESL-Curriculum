### C. Grammar (20 points)

**Part 1.** Circle the correct words (15 points).

1. It ______ rain tomorrow, so take an umbrella. ( **might** / **might to** )

2. The bus may ______ late because of the detour. ( **be** / **is** )

3. Do you know where ______? ( **the meeting is** / **is the meeting** )

4. A garden isn't as expensive ______ a parking lot. ( **as** / **than** )

5. I ______ with you. I think it's a great idea. ( **agree** / **am agree** )

6. The TV is on, but no one is watching it. Please ______. ( **turn it off** / **turn off it** )

7. Your shoes are on the floor. Please put ______ away. ( **them** / **it** )

8. I went to the store ______ some milk. ( **to buy** / **for buy** )

9. I enjoy ______ to new places. ( **traveling** / **to travel** )

10. I want ______ two days off in June. ( **taking** / **to take** )

11. A scammer is a person ______ lies to get your money. ( **who** / **which** )

12. Don't click on a link ______ comes from a stranger. ( **that** / **who** )

13. ______ I came to this country, I lived with my parents. ( **Before** / **After** )

14. When I came here, I ______ understand the bus driver. Now I can. ( **couldn't** / **can't** )

15. I've lived here ______ 2019. ( **for** / **since** )
