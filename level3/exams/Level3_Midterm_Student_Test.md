### C. Grammar (20 points)

**Part 1.** Circle the correct words (15 points).

1. I don't have a car, ______ I take the bus. ( **because** / **so** )

2. Why did you stay home? ______ I was tired. ( **Because** / **So** )

3. What does your brother ______? He's tall, and he has a beard. ( **look like** / **like** )

4. What is your boss ______? She's very friendly. ( **like** / **look like** )

5. Do you know Mr. Lee? Yes, I see ______ every day. ( **he** / **him** )

6. I ______ live in a village. Now I live in a city. ( **used to** / **use to** )

7. Did you ______ walk to school? ( **used to** / **use to** )

8. What ______ you doing at 8:00 last night? ( **was** / **were** )

9. I was waiting at the light ______ a car hit my car. ( **when** / **while** )

10. A: The phone is ringing. B: ______ get it. ( **I'll** / **I'm going to** )

11. We bought the tickets last week. We ______ visit my mother on Sunday. ( **will** / **are going to** )

12. If it ______ tomorrow, I'll take the bus. ( **rains** / **will rain** )

13. If the power goes out, we ______ stay with my sister. ( **are** / **will** )

14. I'd like ______ this shirt. It's too big. ( **return** / **to return** )

15. ______ I see the receipt, please? ( **Could** / **Do** )
