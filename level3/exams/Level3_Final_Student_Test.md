### C. Grammar (20 points)

**Part 1.** Circle the correct words (15 points).

1. Is this your umbrella? Yes, it's ______. ( **my** / **mine** )

2. ______ keys are these? ( **Who** / **Whose** )

3. I was walking home ______ I found the wallet. ( **when** / **while** )

4. I'm good at ______ things. ( **fixing** / **fix** )

5. Are you interested ______ working with children? ( **in** / **at** )

6. I don't mind ______ on weekends. ( **work** / **working** )

7. ______, put in the clothes. Next, add the detergent. ( **Finally** / **First** )

8. The concert was very ______. I loved it! ( **exciting** / **excited** )

9. The movie was long, and I was ______. ( **boring** / **bored** )

10. Is ______ wrong with the sink? ( **anything** / **nothing** )

11. I knocked, but ______ answered. ( **anyone** / **no one** )

12. If you don't fix the heater, I ______ call the office again. ( **will** / **am** )

13. I bought the books yesterday. I ______ start the class on Monday. ( **am going to** / **will** )

14. I hope ______ my diploma next year. ( **to get** / **get** )

15. I ______ work nights. Now I work days. ( **used to** / **use to** )
